# CS coursework

My Java homework from CS1100 and CS1110, plus the bits I built for fun on the side.

Every assignment is in here, warts and all. I'm not going back and cleaning up the early
ones - I'd rather be able to look back and see how much better this got!

## The assignments

- `CS1110_HW2`, `HW3_CS1100`, `HW7` - graded homework
- `Gomuku_HW1` - five in a row. The win check across every direction was the fun part
- `BankAccount` - classes, objects, and the moment `private` finally made sense
- `FinanceCalculator` - a calculator that actually does something I'd use

## The ones I just felt like making

- `PracticeGame`, `Freeplay`, `practice_quiz`, `Particle`, `Test` - messing around. Some of
  these are more of a playground for me than working software, and that's fine!

## Running any of it

These are IntelliJ projects. Open the folder, find the class with `main` in it, hit run.
Nothing fancy going on here.

## A note

`primes.txt` and the compiled `.class` files aren't in here. They're output, not code, and
one of them was 390 MB (oops).
